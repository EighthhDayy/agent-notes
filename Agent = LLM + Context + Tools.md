Agent = LLM + Context + Tools


LLM is the brain of an Agent: It is not merely a set of model parameters, but the entire decision-making core of the Agent—understanding intentions, reasoning and planning, and making judgments. Just as the human brain is more than a collection of neurons and also includes ways of thinking shaped by experience, an LLM's capabilities come from two sources: the world knowledge and language abilities acquired through pre-training, and the decision-making strategies established through post-training. 

Context is the eyes of an Agent: It is not merely the text provided to the model as input, but the representation of information that the Agent receives and retains at each decision point—including observations from the environment, user memory, domain knowledge, its own state, and task progress.

Tools are the hands and feet of an Agent: Here, "tools" refer to the interfaces that an Agent uses to perceive or modify the external world, including tool definitions, calling protocols, and adapters—ranging from predefined tool calls to dynamically generated code, from delegating tasks to sub-Agents for collaboration to proactively communicating with users.
